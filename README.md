## Описание проекта

Telegram-бот помогает пользователям выбирать фильмы по 12 жанрам. Бот рекомендует фильмы, которые пользователь ещё не видел, позволяет добавлять их в избранное и просматривать историю.

**Уникальная особенность:** Все действия пользователей сохраняются в Django админ-панель, где можно отслеживать активность и управлять данными.

## Используемые технологии

| Технология | Назначение |
|------------|------------|
| Python 3.9 | Язык программирования |
| Django 4.2 | Админ-панель и база данных |
| pyTelegramBotAPI | Telegram Bot API |
| SQLite3 | Хранение данных |
| HTML/CSS | Базовая веб-страница |

## Функции бота

✅ 12 жанров фильмов (комедия, ужасы, боевик, драма и др.)

✅ Рекомендация случайного фильма

✅ Добавление фильмов в избранное

✅ Просмотр списка избранных фильмов

✅ Фильмы не повторяются (умный алгоритм)

✅ Сброс истории при начале заново

✅ Демо-платежи (заглушка)

✅ Админ-панель Django для просмотра статистики

## Команды бота

| Команда | Что делает |
|---------|------------|
| `/start` | Запускает бота и показывает меню |
| `/menu` | Показывает главное меню |
| `/random` | Случайный фильм из любого жанра |
| `/history` | Показывает избранные фильмы |
| `/help` | Справка по командам |

## Как работает бот

1. Пользователь нажимает `/start`
2. Бот показывает кнопки с 12 жанрами
3. Пользователь выбирает жанр
4. Бот рекомендует фильм (который ещё не показывал)
5. Можно добавить фильм в избранное или посмотреть следующий
6. Все действия сохраняются в админ-панель Django
